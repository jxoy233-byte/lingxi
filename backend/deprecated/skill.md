# 🔍 Skill: Bocha

Bocha 是一个**新闻/时效性**搜索引擎，支持按时间范围筛选

**文件名称**: `Bocha.py`
**类型**: 搜索 / 信息检索
**能力**: 实时网页搜索 + 多时间范围筛选

**适用场景**：
- 需要**最新新闻、近期动态**
- 按时间过滤：当天、一周、一个月内的结果
- 明确要求"今天的"、"本周的"、"上个月的"

**适用关键词**：新闻、动态、消息、发布、近期、最新

**函数**：
- `search_web(query, freshness, count=3)` — 搜索，`freshness` 可选 `oneDay`/`oneWeek`/`oneMonth`
